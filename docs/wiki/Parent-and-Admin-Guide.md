# Parent and Admin Guide

The administrator controls accounts and course oversight.

## Initial access

The application begins with the seeded administrator credentials used during initial setup. The administrator should immediately replace the default password before production use.

## Administrative responsibilities

* create and manage student accounts;
* reset passwords;
* review grades;
* inspect mastery;
* manage lesson content;
* review assignments requiring human judgment;
* monitor reading and course progress;
* intervene when repeated remediation does not resolve a weak skill.

## Privacy principle

A student or parent account should only see records it is authorized to see. Administrative access should not be casually shared.

## Interpreting mastery

Do not treat a single percentage as the whole learner.

Look for patterns: repeated premise errors, weak vocabulary, strong reading but weak physics, or strong factual recall but poor transfer.

Those patterns are more actionable than a raw total score.
