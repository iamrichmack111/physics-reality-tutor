# Mastery Engine

![Mastery Dashboard](../assets/screenshots/07-mastery-dashboard.png)

The mastery engine treats the course as a network of competencies.

## Core loop

**Diagnostic → Recommended activity → Assessment → Skill update → Review or advancement → Transfer test**

## Competency dimensions

Possible dimensions include physics knowledge, reading comprehension, vocabulary, definition precision, premise identification, syllogistic validity, evidence evaluation, fallacy recognition, argument construction, counterargument, and written explanation.

## Why independent scores matter

A student can be excellent at reading while weak at formal inference. A single course percentage hides that difference.

The system should therefore remediate the skill, not automatically repeat the entire unit.

## Spaced review

A mastered skill should return periodically. A conceptual schedule can use intervals such as 1, 3, 7, 14, and 30 days, with the actual interval adjusted according to performance.

## Transfer

The strongest evidence of mastery is successful application to an unfamiliar problem.

A learner who memorizes the Limited Rendering syllogism has not necessarily mastered syllogistic reasoning. A transfer test supplies a different proposition and asks the learner to construct or evaluate the reasoning without copying the original example.
