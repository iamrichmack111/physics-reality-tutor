# Physics & Reality Tutor Wiki

Physics & Reality Tutor is a self-paced interdisciplinary course platform combining physics, philosophy, Aristotelian argument, ELA, scientific experimentation, and mastery learning.

## Core loop
Read → Define → Argue → Debate → Experiment → Evaluate → Write → Mastery.
